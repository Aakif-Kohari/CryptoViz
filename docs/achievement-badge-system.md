# Achievement & Badge System

CryptoViz incorporates an achievement and badge system to drive long-term engagement, encourage learning retention, and reward exploration.

## Core Features

- **Automatic Unlocks**: Badges unlock automatically based on visualizer exploration count, challenge completions, and daily streaks.
- **Achievement Gallery**: Interactive responsive UI component displaying all available badges, categories, and requirement criteria.
- **Persistent Storage**: Unlocks persist locally via clean storage handlers.
