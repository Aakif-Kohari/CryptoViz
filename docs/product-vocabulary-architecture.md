# Standardized Product Vocabulary & Information Architecture

This document defines the canonical product vocabulary and core navigation hierarchy for CryptoViz to reduce cognitive load and eliminate confusing parallel terminology.

## Terminology Standard

| Original Fragmented Term | Standardized Canonical Term | Definition / Usage Scope |
| :--- | :--- | :--- |
| **Hub / Explorer / Sandbox** | **Visualizer** | Interactive execution environment for specific ciphers and primitives. |
| **Assistant / Advisor** | **Advisor** | Interactive guidance tool that helps users select ciphers based on security requirements. |
| **Collection / Library** | **Reference Hub** | Consolidated index of ciphers, standards, RFCs, and comparison tools. |
| **Question Bank / Quiz** | **Practice Challenge** | Interactive micro-quizzes, daily challenges, and timed decryption activities. |

## Core Product Pillars

1. **Learn**: Conceptual documentation, cipher lifecycles, case studies, and myth busters.
2. **Practice**: Hands-on interactive visualizers, attack simulators, sandbox, advisor, and guided challenges.
3. **Reference**: Comprehensive cipher indexes, comparison matrix, standards library, and benchmarks.
