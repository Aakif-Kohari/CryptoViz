# Interactive Cryptography Roadmap

The Interactive Cryptography Roadmap gives CryptoViz learners a guided path from
fundamentals to advanced implementation and cryptanalysis concepts.

## Route

```text
/resources/roadmap
```

## What the roadmap includes

- progress summary cards
- completion percentage bar
- topic status controls
- not-started / in-progress / completed states
- prerequisite locking
- next recommended topic
- level filter
- category filter
- keyword search
- learning outcomes
- related CryptoViz resources
- responsive roadmap cards

## Learning path coverage

- foundations
- encoding, hashing, and encryption
- hash functions
- Merkle proofs
- symmetric encryption
- AES internals
- public-key cryptography
- elliptic-curve cryptography
- password hashing and KDFs
- cryptanalysis basics
- standards and real-world practice

## Manual testing

1. Open `/resources/roadmap`.
2. Confirm progress summary cards render.
3. Mark an item completed and confirm completion percentage updates.
4. Filter by Beginner, Intermediate, and Advanced.
5. Filter by category.
6. Search for `AES`.
7. Confirm locked items show prerequisite labels.
8. Resize to mobile width and confirm the page remains usable.
