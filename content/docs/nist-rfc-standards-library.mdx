Cryptography is built on internationally recognized standards that define how algorithms, protocols, and security systems should be designed and implemented. This library provides a curated collection of widely used **NIST FIPS publications** and **IETF RFCs** to help learners explore the specifications behind modern cryptography.

---

## NIST Standards

### FIPS 197 – Advanced Encryption Standard (AES)

Defines the AES block cipher, one of the most widely used symmetric encryption standards.

Applications:

- Secure file encryption
- HTTPS
- VPNs
- Wireless security

---

### FIPS 180-4 – Secure Hash Standard

Defines the SHA family of cryptographic hash functions including SHA-224, SHA-256, SHA-384, and SHA-512.

Applications:

- Digital signatures
- Password storage
- Integrity verification

---

## RFC Standards

### RFC 8446 – TLS 1.3

Defines the latest version of the Transport Layer Security protocol used to secure modern internet communication.

Highlights:

- Forward Secrecy
- Faster handshakes
- Improved cipher suites
- Enhanced security

---

### RFC 5869 – HKDF

Specifies the HMAC-based Extract-and-Expand Key Derivation Function used by TLS 1.3 and many modern protocols.

Applications:

- Session key generation
- Secure key derivation
- TLS 1.3 key schedule

---

## Why These Standards Matter

Understanding official standards helps connect cryptographic theory with practical implementations used in real-world systems. Developers, security professionals, and students can use these specifications to better understand how secure systems are designed and implemented.
