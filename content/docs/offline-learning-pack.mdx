# Offline Learning Packs

CryptoViz provides a robust **Offline Learning Pack System** designed for students, security professionals, and educators who need uninterrupted access to cryptography documentation and interactive algorithm visualizers without reliance on an internet connection.

## Key Features

1. **PWA Service Worker Pre-Caching**: One-click pre-caching of documentation, ciphers, styles, and interactive sandboxes directly into Cache Storage (`cryptoviz-offline-v1`).
2. **Single-File Standalone HTML Apps**: Export self-contained HTML files containing complete styling, formula reference cards, and 100% client-side JavaScript cipher execution engines.
3. **Structured JSON & Markdown Exports**: Export raw pack data and structured markdown for offline notes, Obsidian, or Notion.
4. **Embedded Offline Cipher Playground**: In-page interactive cipher runner for Caesar, ROT13, Vigenère, Atbash, and SHA-256 with zero network latency.

## Available Offline Packs

- **Symmetric & Classical Ciphers Pack**: Covers Caesar, Vigenère, Playfair, AES-256, ChaCha20, and block cipher operating modes (ECB, CBC, CTR, GCM).
- **Asymmetric & Post-Quantum Pack**: Covers RSA key generation, Diffie-Hellman, Elliptic Curves, and NIST PQC standards ML-KEM (Kyber) & ML-DSA (Dilithium).
- **Cryptographic Hashes & KDF Pack**: Covers SHA-256 compression loops, Merkle Trees, and password key derivation (PBKDF2, Scrypt, Argon2).
- **Cryptanalysis & Attacks Pack**: Interactive offline simulators for brute-force key search, frequency analysis, birthday collisions, and avalanche effect heatmaps.
- **Master Cryptography Offline Pack**: All-in-one complete bundle containing all CryptoViz tools and documentation.

## How to Export Standalone Single-File Apps

1. Navigate to `/offline` in the navigation header.
2. Choose your desired learning pack card.
3. Click **HTML App** under *Download Standalone*.
4. Save the generated `.html` file to your computer or USB drive.
5. Double-click the file to open and run interactive visualizers in any web browser without needing internet or web servers.
