# Understanding Brute-Force Attacks

## What is a Brute-Force Attack?

A **brute-force attack** is a cryptographic trial-and-error technique in which an attacker systematically tests every possible combination of characters until the correct password or cryptographic key is discovered.

Unlike **dictionary attacks**, which rely on predefined lists of common passwords or words, a brute-force attack explores the **entire search space**. Given unlimited computational resources and sufficient time, it is mathematically guaranteed to find the correct password.

---

## The Mathematics of Keyspace

The resistance of a password against brute-force attacks is determined by its **keyspace**, which represents the total number of unique password combinations that can be generated.

The keyspace is calculated as:

\[
K = S^L
\]

where:

- \(K\) = Total keyspace
- \(S\) = Size of the character set
- \(L\) = Password length

### Example

An 8-character password containing only lowercase English letters has:

\[
S = 26
\]

Therefore,

\[
K = 26^8 = 208,\!827,\!064,\!576
\]

possible combinations.

If the password length is increased to **16 characters**, the keyspace becomes:

\[
K = 26^{16} \approx 4.36 \times 10^{22}
\]

possible combinations.

> **Key Insight**
>
> Increasing the password length increases the keyspace **exponentially**, making longer passwords significantly more secure than merely increasing the character set.

---

## Entropy: Measuring Password Strength

Password strength is commonly measured using **entropy**, expressed in **bits**.

Entropy is defined as:

\[
H = \log_2(K)
\]

Since

\[
K = S^L
\]

entropy can also be written as:

\[
H = L \times \log_2(S)
\]

Each additional **bit of entropy** doubles the effort required to brute-force the password.

### Common Entropy Levels

| Entropy | Strength |
|---------:|----------|
| < 28 bits | Very Weak |
| 28–35 bits | Weak |
| 36–59 bits | Moderate |
| 60–127 bits | Strong |
| ≥ 128 bits | Cryptographically Secure |

## Online vs Offline Brute-Force Attacks

The practical feasibility of a brute-force attack depends on where password verification occurs.

### Online Rate-Limited Attacks

In an online attack, each password guess is submitted to a live authentication server.

Modern applications typically implement protections such as:

- Rate limiting
- Account lockout
- CAPTCHA challenges
- IP throttling

As a result, attackers may only be able to test **a few guesses per second**, making brute-force attacks highly impractical.

---

### Offline Password Cracking

Offline attacks occur when an attacker obtains a database of password hashes after a security breach.

Since password verification happens locally, attackers can utilize:

- High-performance GPUs
- FPGA clusters
- ASIC hardware

Tools such as **Hashcat** and **John the Ripper** are capable of testing **billions of password guesses per second** against weak hashing algorithms like **MD5** and **SHA-1**.

Because there is no rate limiting, offline attacks are substantially more dangerous.

---

## Defending Against Brute-Force Attacks

Modern systems defend against offline brute-force attacks using **Key Derivation Functions (KDFs)**.

Instead of computing password hashes instantly, KDFs intentionally require significant computational time and memory.

Common KDFs include:

- `[argon2]`
- `[scrypt]`
- `[pbkdf2]`

These algorithms reduce the attacker's effective guessing rate from billions of guesses per second to only a few hundred, dramatically increasing the computational cost of brute-force attacks.

---

## Key Takeaways

- Brute-force attacks systematically test every possible password combination.
- Password security depends primarily on **keyspace** and **entropy**.
- Longer passwords provide exponentially greater resistance than simply increasing the character set.
- Offline attacks are significantly more dangerous than online attacks due to the absence of rate limiting.
- Modern password hashing algorithms such as **Argon2**, **scrypt**, and **PBKDF2** are specifically designed to slow brute-force attacks and improve password security.
