# Import & Export Test Vectors

Test vectors are standardized inputs and expected outputs used to verify cryptographic implementations.

## Why Use Test Vectors?

- Validate implementations
- Compare algorithm outputs
- Detect implementation errors
- Improve interoperability

## Supported JSON Format

```json
[
  {
    "algorithm": "AES-128",
    "plaintext": "...",
    "key": "...",
    "ciphertext": "..."
  }
]
```
